## OVERVIEW

Project: **poe-helper**

A Chinese navigation page for Path of Exile international server players. It is a visual recreation of `example.html`, rebuilt with modern React tooling.

Stack:

- **Bun** v1.2.17+ (runtime & bundler)
- **React** 19
- **Tailwind CSS** 4.0.6+
- **TypeScript** (strict mode)

## NOTES

- `src/index.tsx` is only used for `bun dev` / `bun start`. The production build entry is `src/index.html` processed by `build.ts`.
- `build.ts` scans `src/**/*.html` as entrypoints, so `src/index.html` is the only build entry.
- The project is client-side rendered: `frontend.tsx` mounts `App` into `#root`.
- `dist/` is gitignored. It is generated by `bun run build` and is what should be deployed to static hosts (GitHub Pages, Vercel, Cloudflare Pages).
- Keep `example.html` as the visual reference; do not delete it unless explicitly asked.
- Canvas animation (`EmbersCanvas`) uses `devicePixelRatio`; ensure cleanup of `requestAnimationFrame` and resize listener on unmount.
